# SecureWatch-Corporate-training-LMS-MERN
Developed a MERN application providing dynamic front-end interfaces enabling effective learner management.

A scalable security training learning management system for safeguarding
the use of the internet for different agencies. The web application used a series of simulation
labs to demonstrate the attacks and risks of the unmonitored use of the internet. After analyzing
the labs the system provided labs containing the mitigation strategies for the attacks and logged
user interaction on the backend using the API. For user assistance the web platform also made
the use of OpenAI LLM-based chatbot to provide users with efficient responses to any emerging
query. The chatbot model was fine-tuned on data that observed user behavior over platforms
and triggers that caused the attacks providing accurate responses to user queries. Her
contributions to this project have been significant, and she has demonstrated a remarkable
ability to provide real-time experiences, producing useful data for users to ensure safety.
